# Regras corporativas de desenvolvimento

Este documento reúne padrões gerais candidatos a serem herdados por todos os SDDs da empresa. Ele não define regras particulares de um projeto nem contratos de um framework ou agente autônomo.

Enquanto `status` não for `aprovado` e `approval_evidence` permanecer nulo, o conteúdo deve ser tratado como proposta de baseline, não como comprovação de conformidade corporativa.

## Escopo e limites

Incluem-se aqui padrões reutilizáveis de engenharia para Oracle Database 19c, SQL, PL/SQL e páginas Oracle APEX da CS Compusoftware. Regras específicas do CSAgent ou de qualquer solução particular — como PKAgent, CSIAHub, helpers, assinaturas próprias, packages corporativas específicas, formato de payload ou estrutura exclusiva de entrega — pertencem às regras do projeto ou do produto e não a esta baseline.

Para stacks ainda não cobertas por esta baseline, como Python, o SDD deve registrar versão, convenções e verificações em `projeto-regras.md`; não deve inferi-las deste documento. Para APEX, aplicam-se as regras `CSAPEX-*` abaixo e, quando necessário, o detalhe rastreável no [índice do guideline CS APEX](../../references/cs-apex/indice.md).
